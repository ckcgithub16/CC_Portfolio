Seam Carving Algorithm

April 2024

Overview

This was a programming assignment for Princeton's Data Structures and Algorithms course, implemented in Java. The SeamCarver class performs content-aware image resizing by identifying and removing low-energy "seams" — connected paths of pixels from top to bottom (vertical) or left to right (horizontal) — that pass through the least visually important regions of the image.

The hero image above shows an energy map of a cityscape. Whiter pixels represent higher energy (more visually important); the red path is the first vertical seam to be removed — the lowest-energy continuous path from top to bottom.

Implementation

The algorithm has three main components:

  • Dual-gradient energy function — computes the energy of each pixel as the squared gradient magnitude in x and y directions using adjacent pixels
  • Seam finding (dynamic programming) — finds the minimum-energy vertical or horizontal seam in O(W × H) time using a DP table
  • Seam removal — removes the identified seam by shifting pixels, returning a new image one pixel narrower or shorter

The implementation spans 295 lines of Java and received a perfect score. Both horizontal and vertical seam removal are supported, enabling 2D resizing.
