Targeting And Range-Automated Projectile Launcher (TAR-APL)

Fall 2019 – Spring 2020

Overview

I designed and constructed a projectile launching system that measures the distance to a target and automatically adjusts the launch angle based on that measurement. The system uses a Raspberry Pi microprocessor programmed in Python to control a servo motor that sets the correct elevation angle for a given range.

This project was completed as part of the Northrop Grumman High School Involvement Partnership (HIP) program — a two-year mentorship where I worked with three engineers at a local Northrop Grumman facility.
