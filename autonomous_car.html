Self-Driving RC Truck With Obstacle Avoidance and a Safety Filter

March 2025 – May 2025

Abstract

This project involved autonomous operation for two Robotics and Intelligent Systems tasks, where a 1/10-scale RC truck was programmed as an AI car using a classroom-built simulator and programmed in Python using Robot Operating System (ROS) to complete two challenging autonomous driving tasks.

Task 1 — Obstacle Course: The truck navigated 16 waypoints while avoiding up to 20 randomly placed obstacle cubes within a 3:30 time limit. Penalties included +5s for head-on collisions, +3s for brushing, +5s for manual override, and +3s for track departure. Result: 4th fastest of 14 teams.

Task 2 — Safety Filter: An ADAS system continuously monitored manual driver inputs and overrode steering commands that would cause the vehicle to depart the track.

Implementation & Technical Approach

For Task 1, we developed an algorithm operating by assessing each point along our planned path, anticipating obstacle positions, and dynamically modifying safety ellipse radii within a threshold distance. We applied Gaussian filtering (σ=2 physical, σ=5 simulation) for path smoothness and implemented dual-planner safety trajectory cost calculation to handle varying time limitations, allowing simultaneous user control until the last safe moment the full intervention was needed.

For Task 2, we implemented a two-layer safety system using real physical measurements and a simulator running at 1000 Hz for soft trajectory generation. The system calculated trajectory costs over a varying time horizon, allowing simultaneous user control until the last safe moment the partial intervention was needed.

Key Lessons Learned

The most significant challenge was bridging the simulation-to-hardware gap. Algorithms that performed flawlessly in simulation required substantial parameter adjustments for the physical plant. We demonstrated that hardware systems demand well-extended mechanical robustness and comprehensive testing across all operational modes, including real-time obstacle avoidance, path planning, and safety-critical control elements in both simulation and physical environments.

Debugging proved critical: a boolean flag error was causing incorrect controller behavior across multiple scenarios. Systematic testing — isolating each subsystem before integration — saved significant time in later stages of development.
